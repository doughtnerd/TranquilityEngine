# 0171 audio mix (M5): contracts the senior engineer needs from `architecture.md` (round 1)

Each contract is a value, a gate or a behaviour that [api-and-models.md](api-and-models.md) (the **API**) assumes and the architect owns: constants, timing, memory and failure behaviour. I own every byte layout, setting, name and public signature, and publish constants by name. **Status** is round 1: every row is **open** until the architect answers in `architecture.md` or `contracts-architect.md`; contracts are written S1-S14 and the spikes "spike S0-S4"; a `NAME` in capitals is a placeholder the API uses and the architect fixes. `§n` points into the API; **[ARCH §n]** into `architecture.md`. Where a contract needs a different shape from the one assumed, say so and I change the API, not the other way round.
