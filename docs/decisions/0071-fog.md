# 0071. A Fog component sets a World's distance fog, honoured by every engine material

- **Status:** Accepted
- **Date:** 2026-11-04
- **Deciders:** Chris Carlson
- **Supersedes:** —
- **Related:** 0043, 0047, 0052, 0053, 0057

## Context

Worlds have no fog. three.js has scene fog (`Fog` linear, `FogExp2` exponential) that its built-in materials apply when `material.fog` is true. Our shader graph materials patch `MeshStandardMaterial`/`MeshBasicMaterial` (`render/shaderGraph/threeMaterial.ts`), which keeps three's fog chunks, but we've never turned fog on or tested it. Weather (a storm darkening the sky, a fog cloud hiding ships) and atmosphere in general need it.

## Decision

- **Component** `Fog` (`render/components.ts`), like `Environment`: the first enabled one in a World applies.
  - `mode`: `linear | exponential`.
  - `color`.
  - `near`, `far` (linear).
  - `density` (exponential).
  - `affectsSkybox`: whether the skybox fades to the fog colour too. Default false; the background is then the fog colour lerped by `skyboxFog` 0–1.
- **Runtime:** every field can change each frame (a storm fades fog in). The backend updates the existing three fog object instead of recreating it, so materials aren't recompiled. Recompiles happen only when fog is turned on or off, or its mode changes.
- **Materials:** built-in lit, unlit and physical materials, graph materials (all targets), particles (three.quarks materials set `fog: true`) and sprites take fog. A material asset can opt out with `"fog": false` (glows, UI-like meshes). Screen-space UI (0069) and editor gizmos never take fog.
- **Editor:** the scene view shows fog as the game does. The Create menu gets Fog under Lighting.

## Alternatives considered

- **Fog as a post-processing effect** (depth-based). It would work for any material and allows height fog, but it costs a depth pass on tiers without one, and fog would be lost on tiers with post-processing off.
- **Volumetric fog.** Looks best, costs far too much for the Low and Medium tiers. It could come later as a post effect.

## Consequences

**Positive**
- Cheap atmosphere on every tier, changeable at runtime for weather.

**Negative / costs**
- Distance fog only: no height fog, and no local fog volumes. A local fog cloud is a particle effect.

## Deprecates

- Nothing.

## Open questions

- Height fog, as a later post effect.
