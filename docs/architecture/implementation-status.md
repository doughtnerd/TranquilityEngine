# Implementation Status

What exists in `src/engine/` versus what the decision records describe. Updated 2026-10-31, when the first vertical slice landed: enough engine for the Flappy Bird demo to play end to end. The demo is now a sample project in `samples/flappy/` (ADR 0031). The 0032–0035 rows were checked against the code on 2026-11-02 (T17); user guides are in [docs/guide/](../guide/).

Legend: **Done** = implemented as decided · **Partial** = works, with listed gaps · **Not started**.

The confirmation lists the files that still refer to it: scenes and prefabs, `project.json`, scripts that mention its path, and the open scene's unsaved edits. "Don't ask again" is a per-user preference, also in Settings and offered back in the status bar. project.json, the open scene, read-only projects and play mode are refused. After deleting, references are removed (`assetCleanup.ts`): instances of a deleted prefab go with their children, and node references to them become None; component fields and overrides naming the file go back to their defaults; `project.json` autoloads of it are dropped. Scene and prefab files on disk are rewritten (layout kept), and instances in the open scene of a prefab that changed are rebuilt. The open scene is cleaned as one undo step (`ReplaceDocument`), kept when it's saved. Scripts aren't edited; the status bar lists what was cleaned and what still refers to it. The Select/Move/Rotate/Scale tools, the 3D/2D toggle and Focus are a toolbar at the top of the Scene panel, so they move with it. The Scene panel docks, tabs and splits like the others, and the innermost dock fills the space the others leave, with no resize handle. Dropping at its edges adds a dock just outside it, and when it empties the next dock out fills. Saved layouts from before get the scene view as a new filling dock. A collider added beside a sprite starts fitted to it (box: the sprite's size; circle: half its larger side; `spriteSize`). Each component header except Transform's has a ✕ that removes it. On plain nodes this edits the node's components list; on prefab instances and nodes inside them it's an `addComponent` or `removeComponent` override (`SetOverrides`). Removing a component an override added drops that override, and field overrides for a removed component are dropped or renumbered. Only the first of a type from the prefab can be removed there, since a `removeComponent` override takes the first. With several nodes selected, both act on every node that allows it. Each add or remove is one undo step. The scene camera's F key no longer fires while typing in a text field. Each script or engine component's header checkbox switches it on or off (`enabled: false` in the file; on instances an `enabled` override, ADR 0028, removed again when switched back). Disabled components are dimmed, and a mixed multi-selection shows indeterminate. Transform and data components are always on. A grip on each header drags the component to a new place, with a line showing where; Alt+↑/↓ on the focused grip moves it too. Order sets hook order within a node. On a plain node the Inspector lists components in file order, and data components move among the rest (file layout only). On an instance a move writes an `order` override (ADR 0029; `World._reorderComponents` renumbers creation order to match). Moving back to the prefab's own order removes it, and an instance's data components stay put. A left drag on empty viewport space draws a selection box and selects every node lying entirely inside it (its sprite or text rectangle, or its origin if it draws nothing; a prefab instance counts everything drawn inside it), live as the box changes; Shift adds to the selection, Ctrl/Cmd toggles, and Escape puts the selection back. Shift+click and Ctrl/Cmd+click do the same for single viewport clicks. Colliders count as part of their node: a click anywhere inside a box or circle collider selects its node (the smallest collider first, ahead of the sprites drawn there; clicking again cycles to them), and collider rectangles count toward the box and the Alt+click list (`colliderShapes`, `worldToCanvas`).
