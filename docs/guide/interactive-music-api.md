# Interactive music: API reference (replaced)

This page described ADR 0166's music events (`segment`, `playlist` and `musicSwitch` nodes in `*.audioevent.json`), which ADR 0343 replaced with playlists. The scripting API that remains (`handle.music`, `handle.onMusic`, `handle.trigger`, `onMusicBeat`/`onMusicBar`, `Audio.horizon`, `Audio.timeAt`, `Audio.calibration`, `Calibration.fromTaps`, `Audio.latency`) is described in [Interactive music](interactive-music.md), and the format in [Playlists](playlists.md). The handle and event types (`MusicEventHandle`, `MusicEvent`, `MusicHandle`, `MusicPositionAt`, `MusicSeekResult`, `GridSpec`, `GridPoint`, `MusicKind`, `CalibrationApi`, `CalibrationResult`, `AudioLatency`) are still importable from `"myco"` as types; the music format's node and rule types are not.
