## Rules
- **Write only inside your own folder** `spikes/audio-mix/<name>/`. Touch nothing else in the repository (no edits to `src/`, `native/`, `package.json`). **Do not commit.** Use only file, shell and test tools.
- **Cargo:** set `CARGO_TARGET_DIR=/tmp/claude-0/-home-user-TranquilityEngine/f135ce04-10e3-5b06-88ee-a9f64de34c3c/scratchpad/cargo-target` for every cargo command (shared, to save disk; cargo locks it, so a wait is normal). Path-depend on `native/audio/crates/*`; copy code into your folder if you must change it. The `wasm32-unknown-unknown` target is installed.
- **The machine is shared** with other spike agents (4 vCPUs). Timing you take while they compile is unreliable. So: **build, check correctness, and validate your runner with a short smoke run only.** Write a runner (`run.mjs` or `run.sh`) that does the full timed measurement (≥ 5 runs; reports p50, p99, p99.9, max per run, plus the median over runs) and state its expected duration in your reply. **The coordinator runs the timed runs on an idle machine.** Correctness checks do not depend on load: complete them yourself.
- **Cost every run** (owner rule): say what decision a run informs and how long it takes; don't add runs another run already answers (same code, same engine, same host).
- **Evidence:** real content where it matters (`samples/flappy/music/town.mp3`, `samples/sound-lab/audio/*.wav`; you may generate test signals), output checked for correctness, every unmeasured number marked **(est.)**, every unverified claim **[U]**. On this shared VM only p50 and p99 are trustworthy.
- **Today's values** (from the goal's table): a quantum is 128 frames (2,667 µs at 48 kHz); STATUS every 6 quanta (`native/audio/crates/audio-wire/src/schema.rs:75`); peaks for the first 32 buses (`audio-core/src/meters.rs`); `loadPermille` always 0 (`audio-core/src/counters.rs:424`); presets low 64 mixed voices / default 128 / high 256 (`src/plugins/audio/editor/audioSettingsModel.ts`); the wasm mixer is 318,306 B against a 320 KB tripwire gate (a tripwire, not a design limit).
- **Chromium:** Playwright's Chromium is at `/opt/pw-browsers/chromium` (`require('playwright')` works; never run `playwright install`). The container has **no audio device**: use `OfflineAudioContext` or a real `AudioContext` on a null/fake sink; say which.
- **Network:** the proxy blocks most documentation hosts (Audiokinetic, FMOD, Epic, Unity docs, MDN, docs.rs). GitHub (raw.githubusercontent.com, codeload) and crates.io/npm registries work. Say which sources you verified.
- **Cite code** as `path:line` for every claim about how the engine works today.
- **Deliverables:** your folder with code, runner and `README.md` (question, method, results tables, findings, unverified list, how to reproduce); a reply under ~500 words with tables, a recommendation, the runner command and its expected duration, and a "what I read" line.
